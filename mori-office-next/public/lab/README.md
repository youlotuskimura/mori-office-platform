# 社内版（限定公開）用の写真フォルダ

このフォルダには「MORIワークスタイルラボ」資料から抽出した写真を配置します。
**写真は公開リポジトリに含めません（`.gitignore` 済み）。** 公開版（GitHub Pages）はプレースホルダ表示のままです。

## 写真ありの社内版を表示する

1. 納品された写真（`lab-community.jpg` ほか）をこのフォルダに置く。
2. 環境変数 `NEXT_PUBLIC_LAB_PHOTOS=1` を付けて起動する。

```bash
# ローカル（社内端末）で写真ありを確認
NEXT_PUBLIC_LAB_PHOTOS=1 npm run dev

# 限定公開（例：Vercel のパスワード保護環境）にデプロイする場合も
# ビルド時に NEXT_PUBLIC_LAB_PHOTOS=1 を設定する。
```

`NEXT_PUBLIC_LAB_PHOTOS` を設定しない／写真が無い場合は、自動でプレースホルダ表示になります。

> 資料の写真には特定の個人・他社オフィスが含まれます。公開URLには掲載せず、社内限定の用途でご利用ください。
